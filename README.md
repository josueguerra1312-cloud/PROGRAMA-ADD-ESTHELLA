# Separador de bitácoras - folios sin guiones

Los folios se normalizan a siete dígitos en tres puntos: OCR, tabla y escritura final del ZIP.

Ejemplos:

- `2457-001` -> `2457001`
- `REVIEW_2457-001.pdf` -> `REVIEW_2457001.pdf`
- `JAN-07-26_2457-015.pdf` -> `JAN-07-26_2457015.pdf`

Reemplaza todos los archivos del repositorio y reinicia Streamlit Cloud.
